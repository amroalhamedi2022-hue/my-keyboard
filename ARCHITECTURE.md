# Architecture
Initial single Android app with separable packages; extract modules only with real boundaries. Java 17 baseline for dependency-light native View and IME; Kotlin/native inference may be added after evaluation. InputMethodService -> editor policy -> keyboard layout -> InputConnection. No microphone/network/storage permissions yet; no inference placeholders masquerading as functionality. Voice and glide must use cancellable editor-generation sessions and independent ranking/policy, with no persistent raw input. Resource import must use app-private staging and trusted manifest hashes before parsing/loading. Future resource network isolation requires explicit permission architecture, not process separation alone. Inline autofill uses Android framework; don't inspect suggestion contents.
