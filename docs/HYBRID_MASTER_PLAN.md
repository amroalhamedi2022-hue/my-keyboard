## Execution order and acceptance gates
P0 typing foundation — IN PROGRESS. Native IME, deterministic tap routing and multi-touch rollover, complete Arabic/English layouts and long-press variants, adjustable repeat/delay, grapheme-safe deletion, editor-specific actions, stable shared toolbar, no blank rows. Space swipe cursor OR language mode, explicit globe. No auto-correction by default. Gate: actual tap tests in ordinary/multiline/password/numeric/browser fields, selected text and Arabic combining/emoji deletion, portrait/landscape; no dropped or duplicated input in 200 scripted taps on each layout; screenshots from APK, not generated. Owner tablet feedback is decisive.
P1 glide — IN PROGRESS in parallel after P0 interfaces stable. Compare original engine vs license-compatible open source, normalized geometry, indexed candidates, repeated letters, frequency/context ranking and bounded ordered gesture queue; 8k bundled lists are only baseline, expand dialect and lexical coverage, no automatic manual text replacement. Gate: held-out >=200 traces/language, compare top1/top3, false activation, p50/p95 latency against baseline with same corpus; report exact results not synthetic equivalence alone.
P2 voice — IN PROGRESS in parallel. Offline Tiny/Base and alternative engines benchmark on mixed Palestinian/Levantine/MSA/English recordings with consent/licensing. Partial segments, pause/resume, punctuation and spoken commands, script retention, visible state; simplify acquisition, evaluate model sizes. Gate: actual inference on arm64, measured mixed WER/CER and English token error, first partial/final latency, RTF, no retention; compare accuracy/latency with reference behavior when possible. Do not promise Gboard quality before evidence.
P3 Samsung-style tools/layout — IN PROGRESS. Configurable toolbar and overflow, language swipe/cursor mode, native Undo/Redo support where editor implements it, selection, clipboard, emoji, symbols, adjustable hit/hold/repeat, split/floating/full/one hand, four orientation/device profiles, searchable grouped settings and live preview. Gate: each feature reachable without blocking typing; all sensitive/editor-policy checks pass. Floating is pending and must not claim support before actual system behavior test.
P4 Zero visual design — PENDING final direction. Separate semantic theme and renderer, coherent vector icons, dark/light, original Liquid Glass style as optional performant theme, stable animations, adjustable height/spacing, accessibility. Compare actual APK screenshots at phone and Pad5 resolutions against visual references and owner screenshots; assess contrast and layout, no generated images as device evidence. Target 120Hz, p95 frame time <=8.33ms on supported tablet under test; not a guarantee. No glass effects before input usability.
P5 privacy, QA, release — CONTINUOUS. No INTERNET in runtime, no logging/analytics, sensitive-field gates, Autofill provider compatibility, explicit private imports, same owner signature/versionCode increment. Verify actual signed APK installation/update, preserve evidence and source SHA; no debug-as-release. No routine builds; deliberate milestone only. Owner Alpha02 build separate from next milestone.

## First implementation

Adjustable delete interval; optional toolbar controls including native undo/redo. 15 pure JVM assertions passed for state logic; Android wiring is authored, not yet built. Native Undo/Redo depends on editor support, no claim of universal support. Next: verify Alpha02 build, then actual P0 device test and improve key input dispatch, not expand decoration before proof.
