# Batch 04
Native cancellation uses upstream whisper_full_params.abort_callback and an atomic monotonic session watermark; pinned v1.7.6 header verified at https://github.com/ggml-org/whisper.cpp/blob/a8d002cfd879315632a579e73f0148d06959de36/include/whisper.h. Global inference mutex prevents concurrent native contexts. Model loading itself is not interruptible; no warm cache yet. Optional review defaults on; manual editing/cursor moves cancel pending voice. No audio or transcript persistence added.
Adaptive UI: per phone/tablet and orientation profiles, full/split/left/right, height scaling, number row, Arabic-Indic numerals, explicit editor commands and spacebar cursor movement. Split is a center gap in letter rows, not two separate floating windows; width <600dp falls back to full. Toolbar uses editor-owned context menu actions, not clipboard scraping/history; hidden in sensitive/incognito contexts. Geometry based on actual keys remains usable by existing glide algorithm in principle; device testing pending.
All Android and JNI changes are source-only until compile and runtime evidence. No new build triggered by this commit.
