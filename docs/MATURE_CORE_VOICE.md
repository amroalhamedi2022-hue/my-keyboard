# Voice integration, second independent change
Source preparation stage now has an opt-in attach_voice.py path. It copies existing Zero Java voice pipeline and CMake/JNI bridge into a separate Android library, retaining the original JNI package names and using the same pinned Whisper commit. The service wrapper intercepts HeliBoard's voice event; normal input continues through upstream. Credential-protected context preserves the original Zero model storage and preferences even though upstream uses device-protected defaults. Explicit setup, verified imports, pause/stop/discard/review, local partial previews and lifecycle cancellation are authored. No external shortcut IME, no app Internet permission, no raw audio storage. Default upstream incognito blocks voice; voice setup explains this. A real device test must verify toolbar visibility, popup placement, activation, review, cursor handling, cancellation, permission, existing model import and mixed-language accuracy. No claim of working voice or native compile before separate milestone. The current baseline/candidate builds remain unchanged; next deliberate build may use the opt-in workflow label.
