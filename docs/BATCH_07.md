## Continuous segmented dictation follow-up
Optional continuous mode captures audio while a separate bounded worker decodes completed segments (silence or 12 s maximum). It supports cumulative live segment previews and final review/insertion. It is not token-level streaming or true neural VAD. A queue of two pending chunks plus one active inference limits RAM. If the decoder falls behind, recording stops explicitly and queued/backlog/tail chunks drain before review rather than silently dropping a segment. Cap: 5 min wall time, 16k transcript characters. Pause/resume stops and restarts capture; endpoint option stops only single-utterance mode; continuous mode always uses configured silence for segmentation. Segment boundaries may cut words. Native model weights reused only within one session, per-chunk whisper_state created and freed, context released after session. APIs verified in pinned upstream header: whisper_init_from_file_with_params_no_state, whisper_init_state, whisper_free_state, whisper_full_with_state, and _from_state accessors. No cross-session warm model cache. 17 synthetic JVM segmentation and bounded queue checks passed with fake decoder. Actual native build, model inference, Android microphone/preview/backpressure behavior and mixed accuracy are still unverified.
