# Experimental local voice integration
Pinned upstream whisper.cpp v1.7.6 commit a8d002cfd879315632a579e73f0148d06959de36. Native CPU, arm64-v8a and x86_64 only; no Internet permission; CMake fetches pinned source at build time. Runtime mic permission requested only in Setup. Voice is off by default. No model bundled; import exact original multilingual weights via Android document picker:
- Tiny Q5 (~32.2 MB): https://huggingface.co/ggerganov/whisper.cpp/resolve/0b364b566045a405be7225ee1e415a073e04da77/ggml-tiny-q5_1.bin
- Base Q5 (~59.7 MB): https://huggingface.co/ggerganov/whisper.cpp/resolve/f281eb45af861ab5e5297d23694b7d46e090c02c/ggml-base-q5_1.bin
Catalog SHA-256 values from publisher LFS pointers; only exact approved bytes accepted. App-private atomic staging, rehash prior to inference, no audio file or transcript log. Model deletion and selection in setup.
Experimental push-to-record/tap-to-stop single utterance, 30 s cap, basic amplitude gate (not VAD), decode asynchronously, generation guard drops stale results. Native inference currently completes after cancellation; new jobs serialize. User manual typing/cursor move/switch cancels rather than merging dictation. Model loads per utterance. auto language chooses a dominant language; code-switch accuracy, script preservation, streaming, punctuation, VAD, external microphone behavior and warm inference remain unverified. No actual Android compile or device tests yet. Review Android audio capture behavior across vendors and native memory/logging.
