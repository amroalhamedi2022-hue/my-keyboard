# Open glide bridge (experimental)
This source integration is deliberately staged independently from the in-flight voice-only build. It is not CleverKeys or a neural engine. It reuses the existing Zero geometric ranker and 8,000-entry resources per language, using actual upstream Key geometry. Touch admission requires at least 3 distinct letters, travel >=1.35 nominal key widths and time 65–1200 ms, so two-letter swipes are not supported yet. Ordinary taps, multi-touch and popups are delegated unless a gesture has been claimed; after claim upstream pointer events are cancelled. The async worker is bounded and stale results rejected. A new tap can cancel pending swipe output; no candidate strip or trail added yet. Default OFF; incognito/private fields block it. No data sent outside app. The current result is top-1 only and uncalibrated. 17 pure-JVM admission checks actually executed locally; source hashes 1eb704d9f64e00eed3b2b85b87b649577b91a643 and 98eccc165c68a96c27b375ccb216b73ddd469e74. Android integration and actual tap/glide accuracy remain unverified. Evaluate stronger open engines independently and compare on held-out traces. Do not trigger another build until voice build result is known.
