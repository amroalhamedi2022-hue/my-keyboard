# Zero Keyboard
Master functionality in a masterpiece app.

Offline-first Arabic/English Android IME. Initial engineering baseline, not a release. See [requirements](REQUIREMENTS.md), [tracker](IMPLEMENTATION_TRACKER.md), [research](RESEARCH_REPORT.md).

Build with JDK 17, Android SDK 35 and Gradle 8.9: gradle :app:assembleDebug :app:testDebugUnitTest. No signed APK yet. Do not distribute debug artifacts as release. No network or microphone permission in this baseline.
