# Zero Keyboard

Master functionality in a masterpiece app.

Offline-first Android IME, Arabic and English only. Mixed-language offline voice and bilingual glide are the primary research priorities. No automatic correction by default, no tracking, no cloud speech or text processing.

Status: initialization; no verified APK or benchmark yet. See MASTER_PLAN.md, REQUIREMENTS.md and IMPLEMENTATION_TRACKER.md as they are added. Build only at meaningful milestones. Never commit private signing material or user input.
